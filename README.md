# Vestibulize

O **Vestibulize** é um app pensado pra quem vai encarar o vestibular das **FATECs** e quer tudo num só lugar: questões antigas, simulações, acompanhamento e um empurrãozinho extra com IA. A proposta é simples: estudo organizado, sem frescura, com uma pegada mais gamificada pra não virar aquela chatice.

## 🎯 O que o app oferece
- **Banco de questões** de provas anteriores das FATECs  
- **Simulados** que seguem o estilo real da prova  
- **Sistema gamificado** pra manter o ritmo e não desanimar  
- **Testes vocacionais com IA** (em desenvolvimento)  
- **Acompanhamento de progresso** claro e direto  
- Disponível na **Google Play Store**

## 🛠️ Tecnologias
- **React Native**  
- **TypeScript**  
- **Firebase Authentication**  
- **Firestore**  
- **Firebase Storage** (se usar pra mídia ou assets)
