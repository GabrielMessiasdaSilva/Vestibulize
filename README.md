# 📘 Vestibulize  
**Sua preparação para as FATECs de um jeito moderno, gamificado e inteligente.**

O **Vestibulize** é um aplicativo criado para facilitar a vida de quem vai prestar o **vestibular das FATECs**.  
Aqui o foco é simples: **estudar bem, de forma organizada e sem enrolação**, usando tecnologia de verdade — IA, gamificação e um banco completo de questões anteriores.

Disponível na **Google Play Store**, totalmente desenvolvido em **React Native + TypeScript**, com backend e dados no **Firebase / Firestore**.

---

## ✨ Destaques do Projeto
- 🎯 **Focado exclusivamente no vestibular das FATECs**
- 🧠 **Testes vocacionais com IA** (em desenvolvimento)
- 📝 **Banco de questões das provas anteriores**
- 🔥 **Sistema gamificado** que mantém o aluno estudando
- 📊 **Acompanhamento de progresso**
- 📱 App leve, rápido, responsivo e já publicado
- ☁️ Infraestrutura 100% em Firebase

---

## 🚀 Funcionalidades
- Resolver questões por matéria ou prova  
- Simulados completos no estilo da FATEC  
- Recomendação de estudo com base no desempenho  
- Sistema de pontos, níveis e metas semanais  
- Estatísticas claras para o aluno não se perder  
- Conteúdos extras e guias de estudo  
- Teste vocacional com IA (beta em breve)
